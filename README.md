# Ayurveda Knowledge Graph + Herb-Drug Interaction GNN

Research project: one Ayurvedic knowledge graph powering (1) herb-drug interaction prediction,
(2) safe-composition suggestions, (3) cited GraphRAG Q&A, (4) gated Jivha/Nadi input.
Outputs are research risk scores, never medical advice.

Read `progress.md` first: it explains the project and its current state from scratch.
